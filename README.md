# ThoughtUniverse

ThoughtUniverse is a Next.js application built with TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Quality checks

```bash
npm run lint
npm run build
```

The prepared assets in `Explore/` are intentionally kept as source material for future development.
